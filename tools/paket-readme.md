# Studio Elbquartier – Website

Website von Studio Elbquartier (Webdesign & Softwarelösungen, Hamburg) mit neun Beispiel-Websites für erfundene Geschäfte.
Statische Seiten (HTML, CSS, JavaScript mit three.js und GSAP), dazu `kontakt.php` für das Kontaktformular (PHP 8.1+).
Keine Cookies, kein Tracking, keine externen Dienste – alle Schriften und Bibliotheken liegen in `assets/`.

- Start: `index.html`
- Rechtliches: `impressum.html`, `datenschutz.html`
- Quellen und Lizenzen aller Fotos, Filme, 3D-Modelle, Schriften und Bibliotheken: `lizenzen.html`

Lokal ansehen: im Ordner `python3 -m http.server 8765` starten und `http://localhost:8765` öffnen
(die Kamera-Anprobe braucht https oder localhost).
